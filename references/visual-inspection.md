# Visual Inspection

## When Speech Is Not Enough

Inspect visuals when the answer depends on:

- a demonstration, click path, setting, menu, form, or visible result;
- a chart, diagram, comparison, warning, caption, or slide;
- whether the screen supports the presenter's claim;
- exact timing, a fast action, a transition, or a small detail; or
- a requested graphic, thumbnail, or critique handoff.

## Inspection Method

- Start with the approved direct video-understanding route when it can inspect the source.
- Narrow important moments using timestamps.
- Use exact-frame or short-clip extraction when normal sampling may miss the detail.
- Use OCR or vision for visible text, but confirm material small text at a closer frame when practical.
- Compare the state before and after an important action.
- Preserve the source timestamp and explain what the frame proves.

## Coverage Language

Use accurate language:

- **Full source inspected:** the approved tool returned complete stated coverage and the result supports it.
- **Selected moments inspected:** only identified time ranges or frames were checked.
- **Transcript reviewed:** speech text was inspected; visuals were not proved.
- **Page state inspected:** the rendered website state was checked separately from the video.

Do not say “watched the whole video” when only a transcript or sampled frames were used.

## Reuse and Rights

An extracted frame is evidence, not automatic permission to reuse it in marketing. Before sending a frame, logo, person, artwork, or screenshot to graphic production, confirm the intended use and authorization.
